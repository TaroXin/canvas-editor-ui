canvas-editor-ui 预览

同一套工具栏、状态栏和弹窗，分别用四种方式接入 @baohu/canvas-editor。两个 script 页面加载的是构建后的 UMD 文件，与发布到 npm 的产物一致；其余页面直接引用源码，修改后会热更新。

原生 JS（ESM）

import { createEditorUI }，适合 webpack / vite 等构建工具。

script 引入

HTML 中直接用 <script> 引入 UMD，无需构建工具。

Vue 2

Vue.use() 后使用 <canvas-editor> 组件。

Vue 2（script 引入）

页面已有全局 Vue 时，引入后自动注册组件。
